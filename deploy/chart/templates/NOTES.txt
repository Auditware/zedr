zedr control server {{ .Chart.AppVersion }} is installed as "{{ .Release.Name }}".

1. Point DNS for {{ include "zedr.serverHostname" . }} at the address of the Service:

     kubectl -n {{ .Release.Namespace }} get service {{ include "zedr.fullname" . }}

2. Check it:

     curl -fsS {{ include "zedr.serverUrl" . }}/readyz
     helm -n {{ .Release.Namespace }} test {{ .Release.Name }}

3. Back up ZEDR_SIGNING_KEY_HEX from the Secret "{{ include "zedr.secretName" . }}" outside the cluster.
   Deployed agents trust only this key. If it is lost or rotated, every agent has to be reinstalled.
